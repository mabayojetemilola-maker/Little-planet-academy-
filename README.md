# Little Planet Academy Website

Official website for **Little Planet Academy** — a nurturing school in Giginyu, Kano offering Crèche, Nursery, Primary and Islamiyya education.

## How to use

1. Extract this zip (or clone the repo)
2. Open `index.html` in any browser to preview
3. Upload the whole folder to GitHub and enable **GitHub Pages**:
   - Go to **Settings → Pages**
   - Source: Deploy from a branch
   - Branch: `main` / root
   - Save — your site will be live at `https://yourusername.github.io/repo-name/`

## Files

- `index.html` — complete single-page website
- `images/` — all school photos used on the site
- `README.md` — this file
