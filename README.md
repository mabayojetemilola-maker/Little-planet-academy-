# Little Planet Academy Website

Multi-page school website (same structure as AN-NASIHAT Medicals style).

## Pages

- `index.html` — Home
- `academics.html` — Sections & curriculum
- `about.html` — About the school
- `gallery.html` — Photos
- `contact.html` — Phone, WhatsApp, address

## Shared files

- `styles.css`
- `script.js` (hamburger menu)
- `images/` folder (must stay next to the HTML files)

## Deploy (Vercel / GitHub Pages)

1. Extract the zip
2. Upload the **entire folder** (all HTML + CSS + JS + `images/`)
3. Do not upload only `index.html` — pictures and other pages will break

Keep this structure:

```
folder/
├── index.html
├── academics.html
├── about.html
├── gallery.html
├── contact.html
├── styles.css
├── script.js
├── README.md
└── images/
    ├── uniform-portrait.jpg
    ├── kids-jumping.jpg
    └── ... (all 8 photos)
```
