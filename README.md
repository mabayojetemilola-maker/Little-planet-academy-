# Little Planet Academy Website

Official website for **Little Planet Academy** — Giginyu, Kano.

## Important: Folder structure (must keep this)

```
your-project/
├── index.html
├── README.md
└── images/
    ├── colorful-group.jpg
    ├── heart-hands.jpg
    ├── kids-jumping.jpg
    ├── outdoor-group.jpg
    ├── party-celebration.jpg
    ├── plane-visit.jpg
    ├── school-courtyard.jpg
    └── uniform-portrait.jpg
```

**The `images` folder must sit next to `index.html`.**  
If you only upload `index.html`, pictures will be broken.

## Deploy on Vercel (easiest)

1. Extract this zip completely
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Drag the **whole folder** (index.html + images folder together), **or** connect your GitHub repo that contains both
4. Deploy — leave Root Directory empty / default
5. After deploy, hard-refresh the page (or clear cache) so new images load

## Deploy on GitHub Pages

1. Create a new GitHub repository
2. Upload **all files and the images folder** (keep the structure above)
3. Settings → Pages → Source: **Deploy from a branch** → `main` / root
4. Wait 1–2 minutes → site will be live

## Local preview

Open `index.html` in your browser (double-click). Images load from the `images` folder next to it.
